## [1.0.0] - 2026-10-06

First release of [DragoAnt.Roslyn.Shared.Sources](https://www.nuget.org/packages/DragoAnt.Roslyn.Shared.Sources): source-only helpers compiled `internal` into each Roslyn analyzer, source generator and code fix that references the package. Requires [Microsoft.CodeAnalysis.CSharp](https://www.nuget.org/packages/Microsoft.CodeAnalysis.CSharp) 5.0.0 or later; the sources compile on `netstandard2.0`.

### Added

- **Parts:** `Common` (always), `Generators` and `CodeFixes`, picked with `DragoAntRoslynSharedParts`; files linked under `.da.shared/<Part>/` in Solution Explorer; `DragoAntRoslynSharedSourceRoot` compiles them from a local checkout instead ([consuming](https://github.com/DragoAnt/Roslyn/blob/main/docs/consuming.md)).
- **Common:** `SyntaxHelpers` (`GetTargetParameter`, `TryGetConstantString`, `HasAttribute` by symbol or metadata name, `GetFullMetadataName`), `LocationHelpers` (`InStringLiteral`, `InText`, `InAdditionalText`), `DiagnosticHelpers` (`Create`, `Guard`, `Guarded`).
- **Generators:** `EquatableArray<T>` with `ToEquatableArray()`.
- **CodeFixes:** `LiteralRewriter` (`ReplaceStringLiteral`, `ReplaceStringLiteralAsync`).
- Warnings `DARS001` (unknown part) and `DARS002` (a source root without `Common`).
- Every file starts with `// <auto-generated/>` and `#nullable enable`: a consumer's own style and quality analyzers skip it, nullable analysis and `RS1035` still apply.
